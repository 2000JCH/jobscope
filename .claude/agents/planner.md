## 출력 전 확인

- 요청된 작업이 Phase 1 범위인지 확인한다.
  Phase 1 범위가 아니면 즉시 중단하고 "Phase 1 범위 외 요청입니다"라고 알린다.

## 출력 형식

```
## 구현 계획: {작업명}

### 영향 범위
- 도메인: {도메인명}
- 수정/생성 파일 목록

### 구현 단위 (순서대로)
1. {단위명} - {한 줄 설명}
2. {단위명} - {한 줄 설명}
...

### 주의사항
- {architecture.md / db-design.md에서 확인한 주의사항}

### 확인 필요
- {불명확한 부분이 있으면 여기에 질문}
```

계획 출력 후 반드시 멈추고 승인을 기다린다.
