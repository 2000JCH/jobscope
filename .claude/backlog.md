### 지원현황 카드 스와이프 액션

메일/메신저 앱처럼 카드를 좌우로 스와이프해서 빠르게 상태 변경.

- **오른쪽 스와이프** → 합격 처리 (`result = PASSED`)
- **왼쪽 스와이프** → 탈락 처리 (`result = FAILED`)

"다음 단계" 이동은 제외 — 우리 앱은 단계가 고정이 아니라 사용자가 히스토리로 직접 입력하는 방식이라 앱이 "다음 단계"가 뭔지 알 수 없음.

**구현 시 주의사항**
- 현재 카드에 드래그앤드롭(세로 이동)이 구현되어 있어 터치 제스처 충돌 가능성 있음 → 스와이프(가로)와 드래그(세로) 제스처 분리 처리 필요
- 스와이프 중 배경에 색상 힌트 표시 권장 (오른쪽: 초록, 왼쪽: 빨강)
- 실수 방지를 위해 액션 후 짧은 undo 토스트 고려
- 백엔드: `PATCH /api/applications/{id}` 로 result 변경 (기존 API 재사용 가능)
